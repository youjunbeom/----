# Week 4 Python 프로그램

이 폴더에는 힘 단위 변환 프로그램 두 가지와 원형 봉의 축응력 계산기가 있습니다. 아래 실행 명령은 `week4` 폴더에서 실행하는 기준입니다.

## 프로그램

| 파일 | 용도 |
|---|---|
| `force_converter.py` | 터미널에서 힘의 크기를 지원 단위 사이에서 변환합니다. |
| `force_converter gui.py` | Tkinter 창에서 입력값과 단위를 선택해 힘을 변환합니다. |
| `coding.py` | 축력과 원형 봉의 직경으로 단면적과 축응력을 계산합니다. |

힘 변환 프로그램의 지원 단위는 `N`, `kN`, `mN`, `μN`, `kgf`, `gf`, `lbf`, `kip`, `dyn`입니다. 콘솔 버전은 단위 입력에서 공백을 제거하고 대소문자를 구분하지 않습니다. GUI 버전은 목록에서 단위를 선택합니다.

축응력 계산기는 축력을 `kN`, 직경을 `mm`로 입력받고 단면적을 `mm²`, 응력을 `MPa`로 표시합니다. 양의 축력은 인장, 음의 축력은 압축으로 표시합니다.

## 필요한 환경

- Python 3.6 이상이 필요합니다. (사용된 f-string 문법 기준)
- `force_converter gui.py`를 실행하려면 Tkinter와 Tcl/Tk가 포함된 Python 환경이 필요합니다.
- 별도의 외부 Python 패키지는 사용하지 않습니다. 콘솔 프로그램 두 개는 표준 라이브러리만 사용하며, GUI 프로그램은 Tkinter 표준 라이브러리를 사용합니다.

## 실행

터미널에서 이 폴더로 이동한 뒤 원하는 프로그램 하나를 실행합니다.

```powershell
python .\force_converter.py
python ".\force_converter gui.py"
python .\coding.py
```

## 정상 입력 예시

### 콘솔 힘 단위 변환기

값 `2`, 현재 단위 `kN`, 변환 단위 `N`을 입력하면 다음 결과가 표시됩니다.

```text
2 kN = 2000 N
```

값 입력을 기다리는 동안 `q`를 입력하면 프로그램을 종료합니다.

### GUI 힘 단위 변환기

입력값에 `2`를 입력하고 현재 단위로 `kN`, 변환 단위로 `N`을 선택한 뒤 **계산**을 누르거나 Enter 키를 누르면 다음과 같이 표시됩니다.

```text
2 kN = 2000 N
```

### 원형 봉 축응력 계산기

축력 `50` kN, 직경 `20` mm를 입력하면 단면적은 약 `314.159 mm²`, 축응력은 약 `159.15 MPa (인장)`으로 계산됩니다.

## 오류 입력 예시

### 콘솔 힘 단위 변환기

| 입력 | 동작 |
|---|---|
| 값으로 `abc` 입력 | 숫자 변환 오류가 표시됩니다. |
| 현재 단위에 `foo` 입력 | `지원하지 않는 입력 단위입니다.`가 표시됩니다. |
| 변환 단위에 `foo` 입력 | `지원하지 않는 출력 단위입니다.`가 표시됩니다. |

오류 뒤에도 다음 변환을 입력할 수 있습니다.

### GUI 힘 단위 변환기

| 입력 | 표시 결과 |
|---|---|
| 입력값을 비워 둔 뒤 계산 | `입력 오류: 숫자를 입력하세요.` |
| 입력값에 `abc` 입력 후 계산 | `입력 오류:`와 숫자 변환 오류 내용 |

단위는 콤보 상자에서 선택하도록 되어 있습니다.

### 원형 봉 축응력 계산기

| 입력 | 동작 |
|---|---|
| 축력에 `abc` 입력 | 숫자를 입력하라는 안내가 표시되고 축력을 다시 입력받습니다. |
| 직경에 `abc` 입력 | 숫자를 입력하라는 안내가 표시되고 직경을 다시 입력받습니다. |
| 직경에 `0` 또는 음수 입력 | 직경은 0보다 커야 한다는 안내가 표시되고 직경을 다시 입력받습니다. |
