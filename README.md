# 힘 단위 계산기

힘의 값을 여러 단위 사이에서 변환하는 Tkinter 데스크톱 프로그램입니다.

## 지원 단위

`N`, `kN`, `mN`, `μN`, `kgf`, `gf`, `lbf`, `kip`, `dyn`

## 필요한 환경

- Python 3.6 이상
- Tkinter와 Tcl/Tk가 설치된 Python 환경
- 별도의 외부 패키지는 필요하지 않습니다.

## 실행

코드를 `.py` 파일로 저장한 뒤, 터미널에서 해당 파일이 있는 폴더로 이동해 실행합니다.

```powershell
python .\your_script.py
```

`your_script.py`를 저장한 파일명으로 바꿔 주세요.

## 사용 방법

1. 입력값을 입력합니다.
2. 현재 단위와 변환할 단위를 선택합니다.
3. **계산** 버튼을 누르거나 Enter 키를 누릅니다.
4. 결과가 창 아래쪽에 표시됩니다.

예를 들어 입력값 `2`, 현재 단위 `kN`, 변환 단위 `N`을 선택하면 다음과 같이 표시됩니다.

```text
2 kN = 2000 N
```

**초기화** 버튼 또는 Esc 키를 누르면 입력값과 단위 선택이 초기 상태로 돌아갑니다. Delete 키를 누르면 프로그램이 종료됩니다.

## 입력 예시

| 입력값 | 현재 단위 | 변환 단위 | 결과 |
|---:|---|---|---|
| `2` | `kN` | `N` | `2 kN = 2000 N` |

## 오류 입력 예시

| 입력 | 표시 결과 |
|---|---|
| 입력값을 비워 둠 | `입력 오류: 숫자를 입력하세요.` |
| `abc`처럼 숫자로 변환할 수 없는 값 입력 | `입력 오류:`와 숫자 변환 오류 내용 |
